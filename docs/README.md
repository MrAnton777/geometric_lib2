# Geometric lib 

A small Python library for calculating the area and perimeter of geometric shapes.

## Features
- Circle — area and perimeter
- Square — area and perimeter

### `circle.py`

| Function | Description |
|---|---|
| `area(r)` | Returns the area of a circle with radius `r` |
| `perimeter(r)` | Returns the perimeter of a circle with radius `r` |

### `square.py`

| Function | Description |
|---|---|
| `area(a)` | Returns the area of a square with side `a` |
| `perimeter(a)` | Returns the perimeter of a square with side `a` |

## Formulas

**Area**
- Circle: `S = πR²`
- Square: `S = a²`

**Perimeter**
- Circle: `P = 2πR`
- Square: `P = 4a`
